# PF-SEMESTER-PROJECT
Project Overview : The Student Record Management System is a light weight desktop application designed to organize, store, and manage basic student information through an intuitive graphical user interface (GUI). Instead of relying on error-prone manual paper records, this application streamlines routine administrative tasks by allowing users to add, search, update, and delete student records with built-in input validation and persistent local file storage.✨ Key FeaturesAdd Student: Creates a new student record after verifying that all required fields are filled, the GPA is valid, and the roll number is unique.Update Student: Modifies existing student details associated with a specific roll number.Delete Student: Removes an existing student record from the system with a confirmation step to prevent accidental deletion.Find / Next by Roll No.: Quickly searches and retrieves student records using their unique roll number.Clear Form: Resets all data-entry fields so a new record can be entered cleanly.Student Counter: Dynamically displays the total number of student records currently stored in the system.Input Validation & Alerts: Enforces required fields, prevents duplicate roll numbers, validates GPA values (0.00 – 4.00), and displays clear status/error popups.Persistent File Storage: Automatically saves and loads student records locally using Students.txt.🗂️ Data Structure & Validation RulesEach student record is structured around five core fields:FieldType / FormatDescription & Validation RulesrollUnique IdentifierStudent's roll number (required; duplicates are rejected).nameText / StringStudent's full name (required).casteText / StringStudent's caste information (required).fatherText / StringStudent's father's name (required).gpaNumeric (0.00 – 4.00)Student's Grade Point Average (validated within the 0.00 to 4.00 range).🛠️ Technical Details & Project StructureProject1.dev: Dev-C++ project configuration file.main.cpp: Primary C++ source code containing the Windows API GUI controls, event handling, validation logic, and file I/O operations.Students.txt: Local text file (CSV-like format) used to persist student records between application sessions.Core Concepts & Technologies UsedLanguage: C++IDE: Dev-C++GUI Framework: Windows API (windows.h)Programming Concepts: Structures/Records, File Handling (fstream), Input Validation, Event-Driven GUI Programming, and Modular Functions.🚀 How to Run the ProjectOption 1: Using Dev-C++ (Recommended)Clone or download this repository to your Windows machine.Open Dev-C++.Go to File > window.Enter the student details (Roll No., Name, Caste, Father's Name, and GPA) into the input fields.Select the desired action (Add, Update, Delete, Find, or Clear).The application validates the
